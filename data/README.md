# Data

The original structured experiment used the public UCI Diabetes 130-US Hospitals dataset plus mapping tables. The repository intentionally does not redistribute the full raw dataset.

`knowledge_documents.csv` in the original project contained a small synthetic policy/case-note corpus used to validate governed semantic retrieval.

To reproduce the project, obtain the public source dataset from its original distributor, load it into your own Databricks environment, and update catalog/schema references as needed. Never substitute real patient records or PHI for a public portfolio deployment.
